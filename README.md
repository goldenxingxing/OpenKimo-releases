# OpenKimo Releases

OpenKimo 的官方安装包发布仓库。请在 **[Releases](https://github.com/goldenxingxing/OpenKimo-releases/releases)** 页面下载最新版本。

Official release downloads for OpenKimo. Grab the latest installers from the **[Releases](https://github.com/goldenxingxing/OpenKimo-releases/releases)** page.

## 下载 / Downloads

| 平台 / Platform | 文件 / File |
|---|---|
| macOS (Apple Silicon) | `OpenKimo-<version>-arm64.dmg` |
| macOS (Intel) | `OpenKimo-<version>-x86_64.dmg` |
| Windows 10/11 x64 | `OpenKimoSetup-<version>.exe` |

## 安装 / Install

- **macOS**：打开 DMG，把 OpenKimo 拖入「应用程序」。首次打开如提示未验证开发者，请在 App 图标上右键 → 打开。
- **Windows**：运行 `OpenKimoSetup-<version>.exe`，按向导完成安装。
